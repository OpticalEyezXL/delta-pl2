=== A.0 네 극한 ===
  t→0+:  n**(-2*alpha)
  t→∞:   0
  n→0+:  oo
  n→∞:   0
  확인됨: t→∞, n→∞ 모두 0으로 수렴

=== A.3/A.7 열방정식 국소성 논증 ===
  일반 p: ∂²K/∂x² 항 = -n**2*exp(I*n*(x - y) - 2*n**p*t)  (n²에 비례, p와 무관)
  p=2: ∂K/∂t - 2·∂²K/∂x² = 0  (0이어야 국소PDE 닫힘)
  확인됨: p=2에서만 정확히 열방정식으로 닫힘

=== A.7 델타함수 극한 ===
  u=0에서 t→0+ 극한: oo  (발산 = 델타함수 신호)
  확인됨

=== B. rank-2 조석장 고유값 비율 ===
  z축 위 E_ij:
⎡  M                   ⎤
⎢──────    0       0   ⎥
⎢     3                ⎥
⎢4⋅π⋅z                 ⎥
⎢                      ⎥
⎢          M           ⎥
⎢  0     ──────    0   ⎥
⎢             3        ⎥
⎢        4⋅π⋅z         ⎥
⎢                      ⎥
⎢                 -M   ⎥
⎢  0       0     ──────⎥
⎢                     3⎥
⎣                2⋅π⋅z ⎦
  고유값: {M/(4*pi*z**3): 2, -M/(2*pi*z**3): 1}
  기대: (1,1,-2) 비율 확인

=== D. 슈바르츠실트 조석장 vs E_ij (E_ij를 실제로 유도) ===
  Φ=-M/(4πr)에서 실제로 유도한 E_ij (z축 위): E_xx=M*Abs(z)/(4*pi*z**4), E_zz=-M*Abs(z)/(2*pi*z**4)
  우리 비율(E_zz/E_xx) = -2
  [외부 사실, 하드코딩 명시] 슈바르츠실트 비율(R_trtr/R_tthth) = -2
  확인됨: Φ에서 실제로 유도한 E_ij의 비율이 외부 슈바르츠실트 값과 일치

=== E. 진공조건 → 순수 공간곡률 대수적 강제 ===
  Ricci=0으로 풀면 R_rthrth = M/r**3
  [주의] 본문의 -M/r³과 부호가 다르면 부호규약(orthonormal frame 순서) 재확인 필요.
  절댓값과 1/r³ 스케일링 자체는 일치.

=== F. Painlevé-Gullstrand g_rr 일치 ===
  g_rr(ours) - g_rr(Schwarzschild) = 0
  확인됨: 전 차수에서 항등적으로 일치

=== F(연장) 중심 정칙성 ===
  균일밀도에서 g_rr(r→0) = 1
  확인됨: 압력 없이 자동으로 1

=== G. Kerr 고리 특이점 (Newman-Janis) ===
  R² = rho² + (z-ia)² 의 실수부: -a**2 + rho**2 + z**2, 허수부: -2*a*z
  허수부=0 → z=0 (a>0이므로)
  z=0에서 실수부=0 → rho = [a]
  확인됨: 점이 아니라 z=0, rho=a인 반지름 a의 고리

=== H/I. 물질 내부 형태 일치 ===
  뉴턴 조석계수 형태: K(r) = -2*r**2/(A**2 + 2*r**2)**2
  비율(뉴턴/GR)이 상수: 6C²/(A²+2C²) — r 의존성 없음, 확인됨

=== K. 황금비 특이점 (k=1) ===
  r 해: [-1/2 + sqrt(5)/2]
  1/φ = -1/2 + sqrt(5)/2
    후보 -1/2 + sqrt(5)/2: 1/φ와 차이 = 0

=== L.2 반환점 R_min ∝ N^(-1/3) ===
  R_min 후보: [C/(G*N**(1/3)*alpha*m**2)]
    N 지수: -1/3  (기대: -1/3)
  확인됨

=== L.5 노드경로 완전성 (d_space 논의의 재료, 열린문제로 취급) ===
  계수행렬 행렬식: -4  (0이 아니면 선형독립)
  (n+2)² = 1·(n-1)² + -3·n² + 3·(n+1)²
  확인됨: 4번째는 선형결합, 정확히 3차원 닫힘
  주의: 이 3차원이 물리적 d_space=3과 같다는 다리는 없음 (§7 열린문제)

=== M. 위상 닫힘 조건 ===
  m=1: k=0일 때 -1, k=5일 때 -1  (k 무관 확인)
  m=2: k=0일 때 1, k=5일 때 1  (k 무관 확인)
  m=1: -1 (단일권선, 페르미온형)
  m=2: +1 (이중권선, 4π 이중덮개)

=== T. 파울리 클리포드 대수 ===
  [외부 사실, 하드코딩] 파울리행렬 자체는 표준 대상이며 Δ에서 유도되지 않음.
  검증하는 것은 '이 표준 행렬들이 클리포드 대수를 만족하는가'이지 'Δ가 파울리행렬을 낳는가'가 아님.
  확인됨: {σi,σj}=2δij 전 성분 일치

=== T. Weyl 분산관계 ===

  확인됨: H² = (nx²+ny²+nz²)·I, 선형고유값 E=±|n|
